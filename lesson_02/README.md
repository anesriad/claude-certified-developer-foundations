# Lesson 2: Setting Up Your Claude Development Environment

## What we covered
- Virtual environments and why we use them
- Installing the `anthropic` SDK and `python-dotenv`
- Keeping your API key in a `.env` file that git ignores

## What we did in the lab
- Created and activated a `.venv`
- Installed the packages and saved them with `pip freeze > requirements.txt`
- Added the key to `.env` and listed `.env` and `.venv/` in `.gitignore`
- Ran `verify_setup.py`, which prints `Environment ready`
